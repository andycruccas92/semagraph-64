# Codex Operating Model

Codex tasks must preserve the pure mathematical boundary.

Allowed:

- TypeScript contracts;
- deterministic tests;
- synthetic examples;
- documentation;
- benchmark scaffolding.

Forbidden unless explicitly authorized:

- LLM provider runtime;
- database persistence;
- network calls;
- application-specific integrations;
- symbolic catalogue reintroduction;
- state assignment by language model in the canonical State64 path.
