# SemaGraph Core Skill

SemaGraph v0.7 treats State64 as a pure mathematical transition space.

Rules:

- Preserve deterministic state anchoring from declared parameters or observed measurements.
- Preserve the distinction between raw chains, ordered mutation signatures and net mutation masks.
- Keep observed, simulated, inferred and validated transition authority distinct in the generic kernel.
- Do not introduce application-specific integrations, persistence, provider runtimes or network access without explicit authorization.
- Do not assign observed State64 values through a language model in the canonical State64 path.
