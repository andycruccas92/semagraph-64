## Research questions

1. Can a small binary visual language encode useful contextual states for LLM agents?
2. Can symbolic trajectories reduce noise in long-term agent memory?
3. Can state transformations improve agent routing decisions?
4. Can human users learn the language quickly?
5. Can the system represent simple emotional, pedagogical, or decision states without overclaiming?
6. Does symbolic memory outperform text summaries for context continuity in narrow tasks?

## Evaluation ideas

- human interpretability tests;
- state assignment consistency tests;
- retrieval relevance tests;
- agent routing improvement tests;
- context compression tests;
- trajectory reconstruction tests.

Do not use traditional interpretation as ground truth. Treat it as one historical interpretive layer among others.
